# راهنمای فایل‌های داده (دیتاست‌های مقاله)

هر سه دیتاست از مخزن عمومی UCI Machine Learning Repository گرفته شده‌اند و در مقاله استفاده شده‌اند.
نسخه‌های تبدیل‌شده:

- **data_excel/** → فایل‌های xlsx (دابل‌کلیک کنید، مستقیم در Excel باز می‌شوند) ⭐
- **data_csv/** → فایل‌های CSV با سرستون (برای Google Sheets / پایتون)
- **data/** → فایل‌های خام اصلی (پسوند .data — متن ساده با جداکننده کاما)

---

## ۱) parkinson.xlsx — پایش پارکینسون (۵۸۷۵ سطر × ۲۲ ستون)

| ستون | معنی |
|---|---|
| subject# | شماره بیمار (۱ تا ۴۲) |
| age / sex | سن / جنسیت |
| test_time | زمان سنجش از شروع مطالعه (روز) |
| **motor_UPDRS** | ⭐ متغیر هدف مقاله — امتیاز شدت حرکتی بیماری (ارزیابی پزشک) |
| total_UPDRS | امتیاز کل |
| Jitter(%) تا Jitter:DDP | ۵ معیار لرزش بسامد صدا |
| Shimmer تا Shimmer:DDA | ۶ معیار نوسان دامنه صدا |
| NHR / HNR | نسبت نوفه‌به‌هارمونیک / نسبت هارمونیک‌به‌نوفه |
| RPDE / DFA / PPE | سه معیار آشوب‌گونه/فرکتالی سیگنال صدا |

## ۲) heart_cleveland.xlsx — بیماری قلبی کلیولند (۳۰۳ سطر × ۱۴ ستون)

| ستون | معنی |
|---|---|
| age, sex | سن، جنسیت (1=مرد) |
| cp | نوع درد قفسه سینه (۱-۴) |
| trestbps | فشار خون در حالت استراحت |
| chol | کلسترول سرم |
| fbs | قند خون ناشتا > ۱۲۰؟ (1/0) |
| restecg | نوار قلب استراحت (۰-۲) |
| thalach | بیشینه ضربان قلب |
| exang | آنژین ناشی از فعالیت (1/0) |
| oldpeak | افت قطعه ST |
| slope, ca, thal | شیب قطعه ST، شمار عروق اصلی، نوع تالاسمی |
| **num** | ⭐ متغیر هدف — 0 = سالم، 1-4 = شدت بیماری (در مقاله به 0/1 تبدیل شد) |
| مقادیر گمشده | با `?` در فایل خام؛ در نسخه اکسل خالی‌اند |

## ۳) breast_cancer_wdbc.xlsx — سرطان پستان ویسکانسین (۵۶۹ سطر × ۳۲ ستون)

| ستون | معنی |
|---|---|
| id | شناسه نمونه |
| **diagnosis** | ⭐ متغیر هدف — Malignant (بدخیم) / Benign (خوش‌خیم) |
| radius_mean … fractal_dimension_worst | ۳۰ ویژگی شکل هسته سلول از تصویر سوزنی (میانگین/خطای معیار/بدترین مقدار) |

## نکته برای Excel
فایل‌های CSV با کدگذاری UTF-8-BOM ساخته شده‌اند تا ستون‌ها و حروف فارسی درست نمایش داده شوند؛
اما ساده‌ترین راه استفاده از نسخه‌های **xlsx** است که هیچ تنظیمی لازم ندارند.
